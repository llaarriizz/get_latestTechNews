# get_latestTechNews

A simple Go CLI tool that fetches and displays the latest tech news from [TechCrunch RSS feed](https://techcrunch.com/feed/).

## Usage

```bash
go run main.go
```

Or build and run:

```bash
go build -o get_latestTechNews
./get_latestTechNews
```

## Output

Displays each article as:
```
$ Title
- Description
```

## Dependencies

- Go 1.27.1+
